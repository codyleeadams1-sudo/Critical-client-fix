# Critical Client (Fabric, Minecraft 26.3)

Press **Right Shift** in game to open the module menu.

## Get the jar (GitHub builds it for you)
1. Push/upload this repo to GitHub.
2. Open the **Actions** tab - the build starts automatically (or click **Run workflow**).
3. When it is green, open the **Releases** page (right side of the repo) and download `criticalclient-1.0.0.jar`.
   (It is also under the run > Artifacts.)
4. Put the jar in `.minecraft/mods` with Fabric Loader 0.19.5+ and Fabric API 0.160.5+26.3.

Modules: Fullbright, Zoom (hold C), Armor Durability, Tool Durability, Numbered Hotbar, Coordinates,
FPS Counter, Clock, Totem Counter, Auto Sprint. Toggles save to config/criticalclient.json.
